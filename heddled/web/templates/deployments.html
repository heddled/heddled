Publish

Your agents keep working while you edit them, so you need a way to say "this version is the one people should get". That's what publishing is. dev is your own sandbox, staging is for showing colleagues, and prod is the real thing.

dev always runs the version you are editing. Staging and prod run the version published to them and keep running it while you edit — that is what makes publishing a decision rather than a note. Publishing to prod asks for a passing test run on that exact version first; you can override it, but it will ask.
